# pedilopuej.com

Web de Pedilo Puej: inicio, política de privacidad y eliminar cuenta. HTML estático, sin build.

- `/` → `index.html`
- `/privacidad/` → la URL que piden Google Play y la pantalla de "Iniciar sesión con Google"
- `/eliminar-cuenta/` → la URL de borrado de cuenta que pide Google Play

Se publica con GitHub Pages (rama `main`, carpeta raíz). `CNAME` fija el dominio.
